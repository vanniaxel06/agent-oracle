Flash Agent Oracle

Physical status displays for agents and automated systems. Source on GitHub

Plug an ESP32-2432S028R in over USB and press the button.

Chrome or Edge on desktop — flashing uses Web Serial, which Firefox and Safari don't support. Nothing is uploaded anywhere; your browser talks to the board directly.

If it says "Failed to initialize"

Common, and not a broken board. The flasher resets the ESP32 into download mode over the USB-serial chip, and the CH340 on these boards doesn't always take it first go.

  1. Just press Install again. It often works on the second attempt.
  2. Hold the BOOT button (small button on the back, near the USB ports) while clicking Install, and let go once it starts writing.
  3. Make sure nothing else holds the port — a serial monitor, Arduino IDE, or a PlatformIO upload in another window.
  4. Use a data USB cable. A charge-only cable powers the screen fine, so the board looks alive while no port ever appears.

Still stuck? pio run -t upload from the repo always works, and never needs the BOOT button.

After it flashes

The board has no idea what it is yet. It raises its own wifi network called AgentStatus-Setup-XXXX — join it and you'll get a setup page asking for three things:

  1. Your wifi
  2. Server host — where it polls, no https://
  3. Device key — identifies which screen this is

The host and key are stored on the device, not baked into this image, so one build serves everybody and an update never changes what a screen shows.

No server yet? The repo has a zero-dependency reference server — clone it, node server.js, and you'll have a key and a host in about a minute.

If the screen looks like a photo negative, or stays blank, you have a different board revision. This image is built for esp32-2432S028R. There are two others, they ship different display controllers, and the USB port count does not tell you which one you have — mine has two ports and is the revision documented as having one.

Build the other variants with PlatformIO — see docs/board-revisions.md. Reflashing between them is free and damages nothing.

Worth reading first

docs/decisions.md covers what this cost to learn rather than what worked — mostly that on a board with no PSRAM, memory problems disguise themselves as network and driver faults. It also lists what this doesn't do.
